# RJS Laticínios

Corporate website for a **fictional** dairy brand, built as a MilWeb portfolio piece. The brand, products, testimonials, partners and figures shown on the site are illustrative; it is not affiliated with any real company. The site content is in Brazilian Portuguese.

> **Type:** commercial demo / portfolio (fictional brand) · **Demo:** https://rjs-laticinios.vercel.app

![RJS Laticínios hero section](docs/screenshots/hero.webp)

## Features

- Single-page site with an animated intro (plays once per session, skippable, disabled under `prefers-reduced-motion`).
- Interactive SVG panda mascot and a playful panda section.
- Flavor picker that re-themes the page colors (remembered in `localStorage`).
- Product catalog with category filter, accessible modal product sheet and a procedural 3D view (three / React Three Fiber).
- Recipes, testimonials, partners, animated stats, CTA and footer with contact info.
- Sticky WhatsApp button as the primary call to action (no backend or forms).
- `robots.txt` and `sitemap.xml` generated by the App Router.

![Product catalog](docs/screenshots/products.webp)

## Stack

- Next.js 15.5 (App Router), React 19, TypeScript
- SCSS Modules (no Tailwind)
- Framer Motion, GSAP (ScrollTrigger) and Lenis
- three, @react-three/fiber and @react-three/drei
- react-icons

## Getting started

Prerequisites: Node.js 20 or later and npm.

```bash
npm ci
npm run dev     # http://localhost:3000
```

| Script | Description |
|---|---|
| `npm run dev` | development server |
| `npm run build` | production build |
| `npm run start` | serve the production build |
| `npm run lint` | ESLint (`next lint`) |

No environment variables are required. The canonical URL (`rjslaticinios.com.br`, a fictional domain) is hard-coded in `src/app/layout.tsx`, `src/app/robots.ts` and `src/app/sitemap.ts`.

## Project structure

```
src/
  app/          layout, page, robots, sitemap, icon, global styles
  sections/     page sections (Hero, Products, Recipes, Footer...)
  components/   navbar, panda, animations, 3D, decoration, UI
  constants/    data.ts: all mock content (products, recipes, contact)
  styles/       SCSS tokens and mixins
public/hero, public/products   product renders (see each folder's README)
```

## Limitations

- All content is static and fictional; there is no backend, cart or form.
- Contact uses MilWeb's business WhatsApp number (intentional, for demo purposes); the e-mail uses the fictional `rjslaticinios.com.br` domain.
- There are no automated tests.
